# FORM INDEX · 独立资料目录

目录负责发现 12 个独立网站、筛选研究来源和阅读复刻手册。网站卡片始终直接跳转到各自入口；这里没有 iframe，也不为其他网站添加公共外框。

从仓库根目录运行 `npm run dev -- --mode catalogue`（开发端口5173），或执行 `npm run build -- --mode catalogue` 后通过 `npm run preview` 查看 `/catalogue/`。产物为 `dist/catalogue/`；整体部署时保留其他十二站的并列目录，目录中的跳转才能到达对应网站。

## 本轮优化

- 手机网站卡片改为单列，正文 14 px；海报文字与橙色图形分开布置。原来 390 px 屏幕中的两列卡片只有约 163 px 宽、正文 10 px。
- 来源区增加主题选择、每页 9 条结果、结果范围和重置入口。搜索、状态和主题按 AND 组合；改变筛选会回到第一页。分页把焦点移到结果说明并返回检索工具栏。
- 手机搜索框、主题选择实际字号均为 16 px；菜单、筛选和分页主要控件至少 44 px。菜单支持 Escape 关闭并恢复焦点，锚点导航把焦点带到目标区域。
- 删除不再使用的 12 套 CSS 草图；全部十二站预览图已按优化后的生产版本重拍，图片缺失时显示直接访问提示。
- `DocumentReader.tsx` 延迟加载 Markdown/GFM 解析器与正文。等待时显示加载状态；模块加载失败时显示明确提示、关闭入口和刷新按钮，仍可直接下载原始 Markdown。GFM 表格保留局部横向滚动。

## 实测记录

2026-11-17，生产构建、无缓存 Chromium、桌面 1440×1000 与手机 390×844；字节数为 `PerformanceResourceTiming.encodedBodySize`，不是网络速度测试。

| 指标                    |          优化前 |                      优化后 |
| ----------------------- | --------------: | --------------------------: |
| 首屏 JavaScript         |   491,981 bytes | 267,560 bytes（减少 45.6%） |
| 手机网站卡片列数 / 宽度 | 2 列 / 162.6 px |             1 列 / 343.2 px |
| 手机卡片说明字号        |           10 px |                       14 px |
| 手机菜单点击区域高度    |           36 px |                       44 px |
| 桌面来源区默认高度      |        2,491 px |                    1,264 px |
| 手机来源区默认高度      |        3,952 px |                    2,564 px |

单列卡片增加了手机整页长度（7,946 → 10,577 px），换来完整可读的介绍；来源分页减少默认结果的滚动距离。首次打开手册才请求约 226 KB 的阅读器模块。

已实测 320 / 390 / 768 / 1440 px 无横向溢出、12 张图片完整加载；验证了分页与组合筛选、清空和焦点恢复、三份手册阅读与原文下载、GFM 表格，以及阻断阅读器模块请求后的错误提示和下载。仅声明 Chromium 实测，未进行 iOS 真机验证。

前后截图、首屏与来源区截图及原始测量值位于仓库 `artifacts/optimization/catalogue-*`。全项目正式回归、四轮复盘及交付说明见[优化记录](../../docs/OPTIMIZATION.md)。
